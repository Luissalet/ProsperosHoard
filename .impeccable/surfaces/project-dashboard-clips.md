# Project dashboard and clip canvas

Mode: Operate. User brief, 21 October 2026: entering a project opens a clear
dashboard; create/edit characters and groups in place; open its video directly;
create a clip with simple connected nodes and unmistakable job/output state.
The two supplied close-up references pin the topology: reference media at left,
connected video node at right, large preview, prompt and Run in that node.

Extend the established plum-and-magenta working interface. This is a user-pinned
composition within the existing world, not a new visual identity or a concept
round. Code-led local extension; supplied screenshots are the critique reference.
Use the existing font, contrast tokens, brand icon, languages and themes.

First viewport: compact project identity, actionable project videos, inline cast
creation. Clip view: reference-to-video canvas with the output, prompt and render
action together. Actual reference/output media dominate the canvas.

Signature interaction: choose a reference, see its connection, write motion and
generate in the video node; the same node becomes queued/running/failed/done and
displays that job's output. Motion/end guides become additional connected nodes.
On mobile the same connected task becomes a vertical reference/clip stack with
full-size controls. Existing free-form Spaces remain reachable.

No new model or GPU QA. Synthetic demo media are interaction evidence only.
Never claim generation from the presence of an unrelated project video. Keep
advanced camera/engine/seed, comparison, file upload and library choices.
Production keeps storyboard, text/shot links, preview, quality, history and all
pipeline operations; the process outline and ancillary tools use disclosure.

Quality bar: the supplied clean node-studio example, native form behavior,
visible job state and unambiguous access to the original project/video.
